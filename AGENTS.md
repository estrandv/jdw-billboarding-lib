## External IDs (Critical Architecture)

External IDs bridge Python billboarding ↔ jdw-sc ↔ SuperCollider. They allow live `n_set` modulation of running synths via `/note_modify`.

### Format

Generated by `ElementConverter.resolve_external_id()` in `element_osc_conversion.py:125`:

```
{trackIndex}_{instrumentName}_{counter}{elementIndex}_{counter}_{nodeId}
```

Example: `0_blip_06_0_{nodeId}` — track 0, blip synth, counter=0, element index=6, nodeId template.

### Why `{nodeId}` is Required

jdw-sc's `create_node_id()` in `node_lookup.rs:31` replaces `{nodeId}` with a monotonically incrementing scsynth node ID. Since `curr_id` never resets, every substitution is globally unique — even across sequencer loops.

Without `{nodeId}`, external IDs are deterministic per track position. A new `ElementConverter` starts `id_counter=0` each loop, so loop 2 produces identical IDs to loop 1 → jdw-sc rejects them with `"External id already taken"`.

### Lifecycle

1. **Python** generates external_id with `{nodeId}` template → sends via OSC to jdw-sc
2. **jdw-sc** receives `/note_on_timed`, replaces `{nodeId}` with unique node_id, stores in registry, forwards to scsynth
3. **No automatic cleanup** — jdw-sc has no `/n_end` handler. Registry grows forever unless `/free_notes` explicitly clears entries (used only for effects, via `^effect_(.*)` regex)
4. **`{nodeId}` makes cleanup unnecessary** — even if registry is never cleared, every `{nodeId}` substitution produces a key that no prior call could have generated

### ElementConverter

- **Per-track, per-loop instance**: created once per synth section per loop (`id_counter` resets to 0)
- Resolves elements to one of: `to_note_on_timed` (synths), `to_note_mod` (drones), `to_play_sample` (samplers), `to_note_on` (drone overrides)
- Supports suffixes: `@` (note mod), `$` (drone note_on), `x` (silence), `.` (ignore), `§` (loop start marker)

## OSC Protocol to jdw-sc

| OSC address | Payload | Purpose |
|---|---|---|
| `/note_on_timed` | `[synth_name, external_id, gate_time_ms, delay_ms, args...]` | Note on + auto off |
| `/note_modify` | `[external_id_regex, delay_ms, args...]` | Live param change |
| `/play_sample` | `[external_id, pack_name, index, category, delay_ms, args...]` | Sample playback |
| `/free_notes` | `[regex]` | Kill + unregister matching notes |
| `/note_on` | `[synth_name, external_id, delay_ms, args...]` | Raw note on (no auto off) |
